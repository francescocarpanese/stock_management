# User guide
A minimal user guide is available [here](https://github.com/francescocarpanese/stock_management/wiki).

# Installation

## Developer

- Install `uv` [here](https://docs.astral.sh/uv/)

- On pull the repo

- Install it
```bash
cd stock_management
uv sync
```

- Run the application
```bash
uv run stock_management/tkinter_main.py
```
